# Ansh Kumar Singh | Portfolio

A one-page portfolio built with plain HTML, CSS and JavaScript. No build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages
1. Create a repo named `Anshsingh88.github.io` (or any name) and upload these files to the root.
2. Go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. Your site goes live at `https://anshsingh88.github.io/` (or `/<repo-name>/` for other names).

## Edit your content
- Text, projects, contact details: `index.html`
- Colors and fonts: the `:root` variables at the top of `style.css`
- Photo: replace `assets/photo.jpg` (a square image works best)
